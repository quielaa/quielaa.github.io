# [书店里的阳光](https://quielaa.github.io)

那个转角书店，是苏念逃离喧嚣的避难所。她总在周六下午出现，坐在靠窗的旧沙发里，指尖拂过泛黄的书页，一待就是整个黄昏。她从未留意过那个总是穿着干净衬衫、在历史书架前整理书籍的店员陈默，直到一个雨天，她够不到顶层那本《百年孤独》时，一只修长的手先她一步取下了书。

从此，他们的交集多了起来。陈默会默默把她常看的文学类新书留在柜台，苏念则会分享她读到的有趣句子。他们聊书，聊电影，聊生活里细碎的烦恼，却从不逾越半分。爱情像一本等待被打开的书，封面安静，内里却波涛汹涌。苏念害怕打破这层默契，陈默则担心自己的平凡配不上她的光芒。

苏念生日那天，心情低落地走进书店，却发现她常坐的位置上放着一本手工装订的书。封面是她名字的烫金缩写。她打开，里面是他手抄的、她曾提及喜爱的所有诗歌和段落，最后一页，是他笨拙而真诚的字迹：“故事的开头是你够不到一本书，故事的结局，我希望是你能收下我这颗踮起脚才敢递出的心。” 阳光正好透过窗户，洒在那行字上，也洒进了苏念的心里。
